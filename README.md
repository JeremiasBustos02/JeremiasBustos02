# Proyectos destacados

## 💡 Alumbrado Público — Municipalidad de Lobería

> Plataforma web para digitalizar la gestión del alumbrado público municipal.

Desarrollo realizado como parte de mi **Práctica Profesional Supervisada en UNICEN**, trabajando en un equipo de tres desarrolladores.

El sistema permite gestionar aproximadamente **2.900 puntos de alumbrado georreferenciados** e incorpora funcionalidades para:

- Reclamos vecinales.
- Diagnóstico y reparaciones.
- Gestión de componentes.
- Control y trazabilidad de stock.
- Usuarios y roles.
- Visualización de luminarias mediante mapas.
- Información georreferenciada con PostGIS.

**Stack**

`Java` `Spring Boot` `Spring Security` `PostgreSQL` `PostGIS` `React` `TypeScript`

## 📄 STIAPBA — Gestión y generación de documentos

> Aplicación web desarrollada para agilizar la creación de documentación gremial.

La plataforma reemplaza parte del proceso manual de completar documentos, permitiendo cargar información mediante formularios y generar automáticamente archivos **PDF** a partir de los datos ingresados.

### Funcionalidades principales

- Autenticación de usuarios.
- Gestión de información reutilizable.
- Formularios para generación de documentos.
- Generación automática de PDF.
- Vista previa y descarga de documentos.
- Gestión de usuarios y permisos.

**Stack**

`Java` `Spring Boot` `Spring Security` `PostgreSQL` `React` `TypeScript` `PDFBox`

[![Repositorio](https://img.shields.io/badge/Repositorio-181717?style=flat-square&logo=github)](https://github.com/JeremiasBustos02/stiapba-gremial-zona-6)
